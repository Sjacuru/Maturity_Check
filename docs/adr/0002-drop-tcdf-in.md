# Exclude TCDF IN from the evaluation framework

TCDF IN (Instrução Normativa do TCDF) was considered as a supplementary compliance reference alongside IPMP and Rio Manual. IPMP already covers the full maturity evaluation scope; TCDF IN has a normative structure that doesn't map to IPMP's rubric-based approach, and adding it would expand scope without clear benefit for Phase 1. We exclude TCDF IN entirely — the evaluation framework is IPMP (criteria) + Rio Manual (retrieval hints) only.
